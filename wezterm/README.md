# wezterm
Config: `~/.wezterm.lua` — Nord (Gogh) colors, JetBrainsMono Nerd Font 12pt, 0.94 opacity, CTRL+SHIFT pane/tab keybindings (split, move, resize, zoom, copy mode).
- **Install:** apt from the WezTerm apt repo (`apt.fury.io/wez`).
- **Manual:** requires the JetBrainsMono Nerd Font (see `fonts/`).
