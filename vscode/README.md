# vscode
`settings.json` (color theme: Nord) and `keybindings.json` (stowed to `~/.config/Code/User`) plus `extensions.txt` (from `code --list-extensions`).
- **Install:** snap (`snap install code --classic`). Extensions: `xargs -n1 code --install-extension < extensions.txt`.
- **Excluded:** `mcp.json`, `globalStorage`, `workspaceStorage`, `History` (caches, chats, possible secrets).
